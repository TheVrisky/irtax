# IRTAX Admin UI

این پوشه شامل نخستین نمونه رابط کاربری واکنش‌گرای فارسی پنل مدیریت نسخه 2.0.2 است.

## پیش‌نمایش
فایل index.html را در مرورگر باز کنید یا پوشه admin را روی یک زیردامنه آزمایشی cPanel قرار دهید.

## امکانات فعلی
- سایدبار دسکتاپ و نوار ناوبری موبایل
- نمای کلی و بخش‌های مدیریتی
- نمونه صندوق ورودی پشتیبانی با پنجره مشاهده پرسش و فرم پاسخ
- انتخاب فایل TXT و پیش‌نمایش محلی
- تغییر تم روشن و تاریک

## محدودیت مهم
این نسخه فقط نمونه رابط کاربری است. آمار، کاربران و مطالب داده‌های آزمایشی‌اند. پاسخ‌ها به کاربران واقعی ارسال نمی‌شوند و فایل TXT فقط در مرورگر خوانده می‌شود. هیچ ورود امن یا اتصال پایگاه داده‌ای در این نسخه وجود ندارد. تا زمان پیاده‌سازی API، احراز هویت، CSRF و مجوزهای سمت سرور، این پنل را برای مدیریت واقعی منتشر نکنید.

## مرحله بعد
نسخه PHP 8.2+ و MySQL/MariaDB هاست، Composer، دامنه HTTPS و document root را بررسی کنید. سپس API و احراز هویت را به پنل متصل کنید.
